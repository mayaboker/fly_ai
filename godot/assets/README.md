# Environment assets

All bundled environment assets are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

| Files | Source | Version / resolution | Local changes |
| --- | --- | --- | --- |
| `nature/*.glb` | [Kenney Nature Kit](https://kenney.nl/assets/nature-kit) | 1.0 | Selected tree and rock GLBs only; runtime scale adjusted for metre-based world units. |
| `terrain/forest_leaves_04_*` | [Poly Haven Forest Leaves 04](https://polyhaven.com/a/forest_leaves_04) | 1K | Diffuse and OpenGL normal sources; derived PNGs pack luminance as height and fixed roughness into alpha. |
| `terrain/rocky_terrain_02_*` | [Poly Haven Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02) | 1K | Diffuse and OpenGL normal sources; derived PNGs pack luminance as height and fixed roughness into alpha. |

Terrain3D 1.0.0 is bundled separately under `addons/terrain_3d` and retains
its upstream MIT license in that directory.
